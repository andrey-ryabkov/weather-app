# Weather App

Простое веб-приложение для просмотра текущей погоды и прогноза в выбранном городе на основе данных Open-Meteo.

**[Live Demo](https://andrey-ryabkov.github.io/weather-app/)**

## Возможности

* текущая погода и основные показатели;
* прогноз погоды на ближайшие 24 часа;
* прогноз погоды на 7 дней;
* переключение светлой и тёмной темы;
* сохранение выбранной темы в LocalStorage;
* обработка ошибок при получении данных.

## Технологии

* HTML5
* CSS3
* JavaScript
* Open-Meteo API

## О проекте

Учебный проект для практики JavaScript и работы с API.
